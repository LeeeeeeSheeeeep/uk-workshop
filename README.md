# UK Workshop（英倫工坊）

英語學習工具，圍繞英式英語與正體中文打造。

## 設計理念與功能

多數英語學習軟體仍停留在刷題與機械背單詞，學習過程枯燥，效率也有限。自然學習者在尚未達到 C1 水平時，透過大量閱讀或觀看英文影片，往往遇到過多難點，手機端查詞也不方便。本工具結合內嵌詞庫與自訂 API 接入的 AI 模型，嘗試提供更貼近母語者語料與語感的學習方式。

### 1. 閱讀輔助

- 內嵌詞庫，點擊即可查詞
- 遇到難詞可直接向 AI 提問
- 長難句可請 AI 拆解分析

### 2. 影視精聽與盲聽

- 接入播放器並支援字幕對齊，用於影視劇的精聽與盲聽訓練
- 針對「看字幕聽得懂，關掉字幕就聽不懂」的情況設計
- 字幕時間校準：擷取一段約五秒、從環境音過渡到第一句人聲的音訊，由 AI 辨識人聲出現的位置並記錄當時的播放進度，再找出字幕中對應的時間點，兩者比對後對字幕時間軸做微調。校準只調整時間偏移，不改寫字幕內容

### 3. 寫作與口語

- 以翻譯日常對話的方式，修正語法正確但過於書面、不夠地道、表意不清，以及中式邏輯與翻譯腔等問題
- 內建場景對話，例如買咖啡、訂酒店、接梗等
- 傳統演算法只能比對參考答案，無法主動判斷；本工具由 AI 根據參考答案與使用者作答，給出相應的評級與回饋

## 後續更新計劃

- 精聽模組加入聽音音量限制

## 主要特點

- 高度客製化，支援自訂接入 AI 模型（建議使用 API）
- 無廣告，介面簡約，題目設計為非應試風格
- 圍繞英式英語及正體中文環境建構

## 已知限制

- 非原生 Android 軟體封裝，部分機型適配一般，執行時效能與記憶體佔用較大
- 使用過程中偶現 Bug

## 安裝與使用

- 執行需求：Android 8.0 及以上版本，或直接以瀏覽器開啟 `src/` 內前端檔案
- 安裝方式：前往 `release/` 目錄下載 APK 安裝檔直接安裝

## 目錄結構

- `src/`：前端原始碼與靜態資源
- `release/`：已簽章發行的 Android APK 安裝檔
- `android_template/`：Android 殼層與畫面適配範本
